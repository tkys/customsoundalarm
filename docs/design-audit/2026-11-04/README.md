# 2026-11-04

UI 見直し用のスクリーンショット一式です。撮影条件は
`docs/design-audit/README.md` を参照してください。

## 画面

- `alarm-list`: アラーム一覧（オン／オフ混在・プレイリストのアラームを含む）
- `alarm-add-single`: アラーム追加（1つの音）
- `alarm-add-playlist`: アラーム追加（プレイリスト）
- `alarm-add-backup`: アラーム追加（寝過ごし防止オン）
- `alarm-add-denied`: アラーム追加（アラーム許可なしの案内）
- `alarm-edit-single`: アラーム編集（1つの音）
- `sound-selection`: 音の選択
- `library`: ライブラリ
- `playlist-detail`: プレイリスト詳細
- `onboarding-1-intro` 〜 `onboarding-4-source`: オンボーディング各場面
- `bedside`: ナイトモード（ベッドサイド）
- `import-crop`: 取り込み（音声ファイルの範囲選択）

## 条件

- `light` / `dark` × `ja` / `en`: 上記すべて
- `light_ja_ax5`: `alarm-list`, `alarm-add-single`, `alarm-add-playlist`,
  `alarm-add-backup`, `alarm-add-denied`, `alarm-edit-single`
