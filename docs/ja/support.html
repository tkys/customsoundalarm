どんなファイルが使えますか？

MP3・AAC・WAV・M4A の音声ファイルと、写真ライブラリやファイルアプリにある動画（MOV・MP4）が使えます。ほかのアプリの共有ボタンから My Sound Alarm に送ることもできます。Apple Music や Spotify などの配信サービスの曲は保護されているため取り込めません。

音の長さに制限はありますか？

動画からは最長10分、音声ファイルは長さそのままで取り込めます。選んだ部分がくり返し鳴るので、20〜30秒くらいがおすすめです。

アラームが鳴りませんでした。

「設定 → アプリ → My Sound Alarm」でアラームが許可されているか確認してください。アラームは Apple の AlarmKit で登録するので、マナーモードや集中モード、アプリを閉じているときも鳴ります。それでも鳴らない場合は、iOS のバージョンと状況をメールでお知らせください。

アラームの音が小さいです。

アラームの音量は「設定 → サウンドと触覚 →『着信音と通知音』」で決まります。コントロールセンターの音量はアラームには効きません。Face ID のある iPhone では、画面を見ている間は「画面注視認識機能」で通知音が小さくなります（設定 → Face ID とパスコード）。

バイブレーションを切れますか？

アラームのバイブレーションはアプリからは変えられず、iPhone 側で決まります。すべてのバイブレーションを切るには「設定 → アクセシビリティ → タッチ → バイブレーション」をオフにします（すべてのアプリに影響します）。

寝過ごし防止とは？

設定した時間までにアラームを止めなかったら、同じ音を大きくしてもう一度鳴らす機能です。PRO の機能で、いまは先行公開中です。先行公開中に使い始めた方は、正式版以降もそのまま使えます。

iOS 26 以降の iPhone が必要です。
