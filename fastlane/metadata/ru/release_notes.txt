■ Песни из приложения «Музыка»
При добавлении звука выберите добавление из «Музыки», чтобы выбрать фрагмент для будильника из песен в приложении «Музыка».

■ Открывайте из Пункта управления
Добавьте в Пункт управления кнопки списка будильников и добавления будильника. Касание сразу открывает нужный экран.

■ Первый будильник одним касанием
Пока будильников нет, приложение предложит несколько вариантов времени. Коснитесь одного, чтобы создать будильник.

■ Одноразовый будильник можно продолжить
После того как ваш первый одноразовый будильник прозвенит, в списке рядом с ним появятся кнопки: завтра, по будням, каждый день.
